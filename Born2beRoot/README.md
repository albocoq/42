# Born2beRoot

## ¿Qué es?

Proyecto de administración de sistemas en el que se configura una máquina virtual Debian desde cero. El objetivo es crear un entorno seguro, estable y documentado, siguiendo buenas prácticas de sysadmin.

Incluye particionado con LVM, políticas de firewall (UFW), endurecimiento de SSH, instalación de WordPress con Lighttpn + MariaDB, y una política de contraseñas robusta.

## Lo que aprendí

- Instalación y configuración de un sistema Debian mínimo en virtualización.
- Gestión de particiones, volúmenes lógicos (LVM) y puntos de montaje.
- Configuración de servicios de red: SSH, firewall y políticas de acceso.
- Despliegue de una pila LAMP simplificada (Lighttpd + MariaDB + PHP + WordPress).
- Documentación técnica clara para que otra persona pueda reproducir la instalación.
- Mentalidad de seguridad: acceso mínimo necesario, contraseñas fuertes y servicios restringidos.

## Uso

Este proyecto no tiene código compilable. La entrega consiste en una máquina virtual configurada y un `signature.txt` con el hash de validación.
