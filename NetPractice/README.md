# NetPractice

## ¿Qué es?

Ejercicio teórico-práctico de redes en el que se configuran direcciones IP, máscaras de subred y gateways para conectar distintos hosts y routers. Cada nivel (`level1.json` a `level10.json`) presenta una topología de red que hay que completar correctamente.

No hay código que compilar: la entrega son las configuraciones de red resueltas en la plataforma web de 42.

## Lo que aprendí

- Direccionamiento IPv4: direcciones, máscaras y cálculo de subredes (CIDR).
- Diferencia entre dirección de red, broadcast, gateway y hosts utilizables.
- Enrutamiento básico: qué gateway usar para alcanzar otra subred.
- Lectura de diagramas de topología con routers, switches y hosts.
- Pensamiento sistemático para resolver problemas de conectividad capa 3.

## Uso

Los archivos JSON de este directorio son copias de referencia de los niveles. La práctica se realiza en la interfaz web de NetPractice del campus 42.
